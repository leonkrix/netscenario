# D-042: Repetitions are an option of a run, and the interval is a percentile bootstrap

Accepted (2026-10-31). `--repetitions n` and `run(..., repetitions=n)`; the key `expect` of release 0.3 names the repetitions it needs. Each repetition gets a seed derived from the seed of the run and its number (pinned and documented, as in D-027). The interval of a metric is a percentile bootstrap with 10,000 resamples, seeded from the seed of the run, at 95 percent. Fewer than 5 repetitions are refused: a bootstrap of three numbers says nothing, and the error says so. The method is tested on simulated data with known distributions (the coverage of the intervals, the width against n, the same seed gives the same interval) and has a canary. Alternatives: a Student interval (assumes a normal distribution that delays do not have); BCa (more exact for skewed data and more to get wrong; later, with the same tests); a key in the file (the file would then say how often to run, which is a decision of the test, not of the network).

Refined by [D-074](D-074.md): the interval of the mean is the expanded percentile interval, and the median is selectable.
