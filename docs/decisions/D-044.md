# D-044: "Stable over 100 CI runs" is a workflow

Accepted (2026-10-31). The acceptance test of release 0.2 with a confidence interval is run 100 times by a workflow (`stability.yml`, started by hand and once a week, in a matrix), and any failure fails it; the table of the runs is in its summary and the first complete run is recorded in `docs/ACCEPTANCE.md`. Alternatives: reading the claim as "it passed in the last 100 normal runs" (it would depend on how often the code changes).
