# D-043: Reports are static, and a run can be replayed

Accepted (2026-10-31). `netscenario report <dir> --format md|html|junit` reads result directories. The HTML is one file with inline SVG, no JavaScript and no network request, so it can be attached to a CI run and opened anywhere; a test checks that it has no external reference. The Markdown is made for the summary of a CI job; the JUnit has one test case for each workload with the metrics as properties (the names of the plugin). All three have snapshot tests. A result directory gets `scenario.json` (the canonical scenario); `netscenario replay <dir>` runs it again with the recorded seed and compares the hash and the provenance, and says clearly when the machine is not the one of the original. Alternatives: a report with a JavaScript library (offline use and review get harder); a replay from the name of a file (the file may have changed).
