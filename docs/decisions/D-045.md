# D-045: The parsers of input that is not trusted are fuzzed from release 0.2

Accepted (2026-10-31); QA-03 moves from release 0.3 to 0.2. Release 0.2 adds parsers of input that others write: the lines of metrics from a program, the timeline and the command in the file, the replay file; the receiver already parses every datagram that reaches its port. `cargo-fuzz` targets (nightly Rust, in `fuzz/`, outside the workspace) for the scenario, the units, the packets and records of the agent and the result reader, with the files of `scenarios/` as the first corpus; a scheduled workflow runs each for a few minutes and keeps the corpus. ClusterFuzzLite (which the Scorecard check recognises) and the 24-hour run stay in release 0.8. Alternatives: waiting for 0.3 (the new parsers would ship unfuzzed); property tests alone (they find what the generator can produce, not what a mutation of a real file produces).
