# D-039: An outage and a link that is down are two things

Accepted (2026-10-31). `outage` (LNK-12) is a window in which nothing is delivered and the sender notices nothing (first written as a loss of 100 percent for its length applied as an event, D-038; **revised by D-064**: it is a window at the delivery, not a loss at the entrance, so that a packet that is on its way is not delivered either). `down` and `up` (TML-02) switch the interface of the link: the sender gets errors, the agent counts them as `send_errors`, and the packets that were in the queue are dealt with by the kernel. The format says which is which, and `FEATURES.md` keeps LNK-12 and TML-02 as two lines. Alternatives: one word for both (a test of an application's reaction to a cable pulled and to a radio that goes quiet would not be the same test).
