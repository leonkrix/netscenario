# Reference documents

The pages of this book explain and show. The exact definition of every key, field, option and decision lives in documents next to the code, and they are linked here rather than copied, so there is one place to be right.

| Document | What it defines |
| --- | --- |
| [The command line](https://github.com/leonkrix/netscenario/blob/main/docs/CLI.md) | Every command and option, and the exit codes. |
| [The Python package](https://github.com/leonkrix/netscenario/blob/main/docs/PYTHON.md) | `run`, `start`, `asyncio`, the builder, the result types, the tables. |
| [The pytest plugin](https://github.com/leonkrix/netscenario/blob/main/docs/PYTEST.md) | The fixtures, the marker, and how a test fails. |
| [Doctor and clean](https://github.com/leonkrix/netscenario/blob/main/docs/DOCTOR.md) | What `doctor` checks, `--timers`, and `clean`. |
| [Permissions](https://github.com/leonkrix/netscenario/blob/main/docs/PERMISSIONS.md) | The rights a run needs, and a CI. |
| [Troubleshooting](https://github.com/leonkrix/netscenario/blob/main/docs/TROUBLESHOOTING.md) | Starting from the message. |
